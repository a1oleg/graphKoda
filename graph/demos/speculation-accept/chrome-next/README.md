# Bloom Demo Next

Кнопка **Next** прямо на странице Aura Bloom. Работает самостоятельно, без
ChatGPT, Codex Desktop и их браузерных расширений.

## Установка в Chrome

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение** и выберите эту папку
   `chrome-next` (в ней находится `manifest.json`).
4. Обновите вкладку Aura Bloom. Внизу слева появится панель **BLOOM · DEMO**.

Готовая папка на этой машине:
`C:\GitHub\coldKode\graph\demos\speculation-accept\chrome-next`.

## Использование

Откройте исходную сцену DemoStage1 или пустую сцену. Пустая сцена распознаётся
как **0/3**, и Next загружает первую функцию. Расширение распознаёт остальные
этапы по текущему поиску и счётчику элементов Bloom. Если Bloom не восстановил
строку поиска, для сцен с именами DemoStage1/DemoStage2/DemoStage3 (включая
их копии) используется имя сцены и счётчик. В уже загруженной DemoStage1
кнопка сразу выполняет второй шаг. Незнакомый непустой граф не считается нулевым.

| Next | Поиск | Итог |
| --- | --- | --- |
| 1 | `DemoStage1 NEXT DemoStage1` | 4 узла, 3 связи |
| 2 | `DemoStage2 NEXT DemoStage2` | 16 узлов, 14 связей |
| 3 | `DemoStage1 VALUE_FROM DemoStage2` | 16 узлов, 15 связей |

Кнопка очищает только ввод, ждёт подготовки поиска, нажимает **Run Query**,
проверяет итоговый счётчик и при включённой опции нажимает **Fit all nodes**.
Содержимое сцены накапливается. Сцену и данные расширение не удаляет.
На неизвестной сцене или во время запроса Next недоступна. Для нового показа
откройте исходную сцену; повторный поиск первого этапа не удаляет поздние этапы.

Нужны установленные данные демо, категории DemoStage1/DemoStage2 и связи
NEXT/VALUE_FROM. Раскладка остаётся той, которую вы настроили в Bloom.
Интерфейс Bloom должен быть на английском (как в проверенной сцене).
Расширение не проверяет семантику произвольного графа: используйте его только
на сценах этого демо. Если интерфейс Neo4j изменится, селекторы могут потребовать
обновления. Переключение на другую сцену во время запроса останавливает
последующие действия расширения, но не отменяет уже отправленный поиск Bloom.

## Устройство и проверки

Manifest V3, один изолированный content script. Он подключается только к
`https://console.neo4j.io/projects/*`, а панель видна только на маршруте Bloom.
Нет фонового сервиса, сетевых запросов, разрешений debugger/cookies/storage
или доступа к внутренним объектам приложения.
Документация Chrome: [content scripts](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts).

Для DOM-тестов: `npm ci`, затем `npm test` в этой папке. `npm run build`
собирает чистую установочную папку `dist/bloom-demo-next` без тестовых зависимостей.
Для установки и работы самого расширения Node.js и зависимости не нужны.

Проверено: 17 DOM-тестов (включая нулевой этап, сохранённые сцены без поисковой
строки, ошибки, двойной клик и смену сцены). Переходы 1 → 2 → 3 установленной
версии 1.0.0 проверены кнопкой Next в реальном Aura Bloom: 7 → 30 → 31 элементов.
Исправление распознавания сохранённых сцен в версии 1.0.1 проверено DOM-тестами;
для применения обновления нажмите перезагрузку расширения в chrome://extensions,
затем обновите вкладку Bloom.

Визуальный стенд: `node test/serve.cjs`, затем
`http://127.0.0.1:18773/projects/fixture/studio/bloom`.
