# Bloom Demo Next · 1.0.12

Управление находится в значке расширения на верхней панели Chrome.
Нажмите значок Bloom Demo Next: откроется компактное окно с одной кнопкой
**next** и состоянием текущей вкладки. На странице Bloom панели больше нет.
Закрытие окна расширения не прерывает выполняющийся поиск.

Расширение не очищает сцену при загрузке или обновлении страницы. Для начала показа очистите сцену через Clear Scene средствами Bloom: после подтверждения пустой сцены расширение устанавливает этап 0. Пустая сцена при запуске также получает этап 0. Сохранённая непустая сцена остаётся без изменений; её этап не угадывается по числу узлов. Поиск запускается только нажатием next.

1. `DemoStage1 NEXT DemoStage1` — первая функция и заглавные шаги.
2. `DemoStage2 NEXT DemoStage2` — вторая функция и заглавные шаги.
3. `DemoStage1 VALUE_FROM DemoStage2` — связь параметра с созданием объекта.

После этапа 3 кнопка отключена. Для нового показа используйте Clear Scene в Bloom. Фиксированного ожидаемого числа узлов нет. Расширение не управляет масштабом: автоматический zoom Bloom остаётся без коррекции.

В Perspective Bloom заданы насыщенные цвета обводки из draw.io: вызовы функций — `#007FFF`, значения и параметры — `#BE7000`.

## Установка и обновление

Откройте `chrome://extensions`, включите режим разработчика и загрузите распакованное расширение из `dist/bloom-demo-next`. При обновлении нажмите значок перезагрузки карточки Bloom Demo Next, затем обновите вкладку Bloom. Версия карточки расширения — 1.0.12. Через меню расширений Chrome (значок пазла) закрепите Bloom Demo Next кнопкой-булавкой.

Расширение работает без ChatGPT Desktop, паролей и драйвера базы.

## Проверка и сборка

```powershell
npm test
npm run build
Compress-Archive -Path 'dist/bloom-demo-next' -DestinationPath 'dist/bloom-demo-next.zip' -Force
```

DOM-тесты проверяют сохранение сцены при загрузке, сброс этапа после очистки в Bloom, позднее восстановление узлов, ожидание загрузки, последовательность этапов, двойной клик, ошибки поиска, произвольный размер результата, пустой результат, смену сцены и отсутствие коррекции масштаба. Проверка DOM не заменяет проверку установленной версии в Bloom.
