# Исторические версии HLA

`HLA1.drawio` … `HLA15.drawio` восстановлены побайтно из Git-истории репозиториев `claude-code` и `coldKode`, от 7 августа до 11 сентября 2026 года, в порядке первого появления содержимого. Совпадающие по содержимому версии не дублируются.

`history.json` сопоставляет номер с исходным путём, коммитами, датами, Git blob и SHA-256. Исходные имена: `HLA.drawio`, `HLA copy.drawio`, `HLA copy 2.drawio`.

`HLA0.drawio` находился здесь до восстановления и не изменялся. Восстановленные диаграммы не переразмечались: историческая геометрия сохранена.
