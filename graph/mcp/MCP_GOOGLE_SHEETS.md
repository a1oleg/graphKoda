# MCP Google Sheets

Current server: [google_sheets_mcp_server.py](google_sheets_mcp_server.py)

VS Code MCP config: [../../.vscode/mcp.json](../../.vscode/mcp.json)

This server is started from `.vscode/mcp.json` and runs as a Python stdio MCP server.

## Setup

Install the server dependencies into the project virtual environment:

```powershell
.\.venv\Scripts\python.exe -m pip install -r graph\mcp\requirements-google-sheets.txt
```

Copy the `GOOGLE_*` service-account fields from `graph/.env.example` into the
ignored `graph/.env`. Share the target spreadsheet with `GOOGLE_CLIENT_EMAIL`,
then reload the MCP servers in VS Code.

Verify credentials and API access:

```powershell
.\.venv\Scripts\python.exe graph\mcp\google_sheets_mcp_server.py --check
```
