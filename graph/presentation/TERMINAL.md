# Терминал презентационного окна VS Code

Авторизованный `POST http://127.0.0.1:17844/demo/step`, тот же Bearer-токен,
что у остальных действий презентера. В основном окне запрещён.

```json
{"surface":"terminal","action":"start"}
{"surface":"terminal","action":"read"}
{"surface":"terminal","action":"input","sessionId":"из start","text":"привет"}
{"surface":"terminal","action":"stop","sessionId":"из start"}
```

`start` открывает только встроенный терминал VS Code и запускает Node entry point
скрипта `original:claude:node-pass` напрямую, без PowerShell/cmd. Заглушка модели
включена. Произвольные команды, пути и переменные окружения API не принимает.
Повторный запуск активной сессии запрещён, чужие терминалы не закрываются.
`input` принимает одну строку без управляющих символов и отправляет Enter.
После выхода приложения ввод запрещён; shell после него не остаётся.

`read` сообщает жизненный цикл (`absent`, `running`, `exited`), ID сессии,
код выхода и число отправленных запросов. Это **не чтение вывода** и не проверка
готовности Claude: `readiness: unknown`, `outputAvailable: false`.
Готовность и результат нельзя объявлять на основании одного `running`.
Перезагрузка расширения завершает только принадлежащую API сессию.
