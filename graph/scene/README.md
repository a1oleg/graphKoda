# Управляемая сцена графа

Сцена — представление выбранных фактов Neo4j, не отдельный смысловой граф.
`scene.mjs` читает реальные связи, хранит координаты и генерирует draw.io.
Отдельный MCP `graphScene` удалён. Управление перенесено в
[общий GraphQL API оркестратора](../presentation/README.md).
MCP draw.io inspector остаётся для проверки геометрии.

Верхний граф Фишера: `shuffle —AST_CHILD→ вызов —CALLS→ реализация`.
Прямые выдуманные связи между реализациями не добавляются.

`.drawio` и `.scene.json` версионируются вместе. Перед сценарием сохраните
ручные изменения: чтение учитывает сохранённые координаты, но не произвольную
перестройку структуры. Сценой должен управлять один контроллер.
`expectedRevision` защищает последовательные операции от устаревшего состояния,
но не является межпроцессной блокировкой.

Проверки реального Фишера:

- `node dev/checkFisherGraphScene.mjs`: Aura, сквозные идентификаторы, MCP геометрии.
- `node dev/checkFisherGraphSceneLive.mjs`: настоящий draw.io, GraphQL-сценарий,
  переключение представлений, фокус вложенных функций, указка и раскрытие.
