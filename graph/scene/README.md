# Управляемая сцена графа

Это представление выбранной части Neo4j, а не второй граф и не flow-диаграмма.
Первый пример: `graph/draw/scenes/fisher.drawio`. В VS Code команда
**Фишер: управляемая сцена графа** создаёт/открывает его.

MCP `graphScene` зарегистрирован в `.vscode/mcp.json` и локальном
`C:/Users/a1ole/.codex/config.toml`; сервер запускается также через
`node graph/scene/mcp.mjs` (stdio). После установки перезагрузите окно VS Code
и MCP-клиент. Конфигурация VS Code сама по себе не подключает Codex.

## Координаты и раскрытие

- `scene_read`: видимые узлы, связи, указки, ревизия, дробные координаты draw.io.
- `scene_region`: чтение области по x/y/width/height, без скриншотов.
- `scene_neighbors`: только кандидаты; обязательны `direction: in|out` и `types`.
  Ограничение выдачи явно отмечено `truncated`; ничего не раскрывает само.
- `scene_expand`: один хоп, только перечисленные `targets`, типы и направление.
  Существующие узлы не двигаются. Реальные промежуточные узлы сохраняются.
- `scene_move`: точные x/y выбранных узлов. Начало координат — верхний левый угол
  модели, это не координаты экрана. Размеры и порты читает draw.io inspector.
- `scene_hide`: убирает узлы только из сцены. Neo4j никогда не меняется.
- `scene_pointer`: именованная указка; координаты либо stableId и доли u/v узла.
  `visible:false` скрывает, `live:true` анимирует указку в открытой сцене.
- `scene_sync`: применяет сохранённую сцену в открытом draw.io через мост расширения.
- `scene_live_read`: геометрия открытого редактора, включая несохранённые движения,
  плюс масштаб, сдвиг и прокрутка камеры.

Изменения требуют `expectedRevision` из последнего `scene_read`. Все инструменты
в одном MCP-процессе выполняются последовательно. Не запускайте одновременно
несколько управляющих MCP-процессов для одной сцены.

После expand/move/hide вызывайте `scene_sync` для обновления открытого редактора.
Перед редактированием через MCP сохраните ручные изменения в draw.io: чтение файла
учитывает ручные координаты, но не произвольную перестройку структуры сцены.
Сцена принадлежит контроллеру; для свободного рисования сделайте отдельную копию.

Идентификатор сцены проверяется отдельно от stableId функции: команды не должны
попасть в обычную flow-диаграмму Фишера. Мост локальный, с токеном расширения;
нет произвольного eval, CSS-селекторов или команд VS Code. Если редактор закрыт,
файл сохраняется, но live-команда вернёт ошибку; откройте сцену и повторите sync.

## Фишер

В Aura проверен реальный путь:

`shuffle —AST_CHILD→ вызов getRandom —CALLS→ реализация getRandom`

Аналогично для swap. Прямое выдуманное ребро shuffle → реализация не добавляется.
Названия роли на узлах берутся из labels. Пока это инструментарий просмотра;
автоматический проигрыватель журнала аннотатора сюда ещё не подключён.

`node dev/checkFisherGraphScene.mjs` проверяет MCP на настоящем графе Фишера,
сохраняет раскладку примера и вызывает draw.io MCP validate_geometry.
`node dev/checkFisherGraphSceneLive.mjs` проверяет тот же файл в настоящем локальном
приложении draw.io: чтение, плавное движение указки и синхронизацию модели.

Файлы `.drawio` и `.scene.json` версионируются; последний содержит выбранные
факты, координаты и историю команд. Это состояние представления, не паспорт
экстракции и не журнал реально выполненного аннотирования.
