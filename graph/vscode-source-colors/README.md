# graphKoda Source Colors

Дополнение к штатной тёмной теме: скобки вызовов и квадратные скобки доступа,
более насыщенный корень и светлые члены цепочки. Включение в workspace:
`graphKoda.sourceColors.enabled: true`.

Диапазоны берутся из AST текущего буфера TypeScript, системность — по объявлению
в стандартной библиотеке компилятора. Имена вроде Math не захардкожены.
Импорты разрешаются компилятором. Стандартные библиотеки TypeScript и @types/node
считаются системными; прочие внешние API автоматически системными не становятся.
Провайдер — объект с пользовательскими вызываемыми членами (не массив и не функция).
Это структурное правило подсветки, не новая метка Neo4j. Функциональные привязки
зелёные; имя в позиции вызова сохраняет цвет вызова. Булевы литералы — цвета стрелок.
Это не классификатор провайдеров графа и не замена штатному semantic highlighting.
Диагностика: Output → graphKoda Source Colors. Исходный текст не меняется.
